## v1.0.0 — 2026-07-22

> 正式初始版本 — 组件化架构

### 系统概述

以《凡人修仙传》人界篇为蓝本的硬核修仙文字游戏（GM 模式），覆盖人界篇完整修仙路径（炼气 → 筑基 → 结丹 → 元婴 → 化神）。所有概率判定由 Python 代码强制计算（暗骰机制）。

### 项目结构

```
凡人修仙传-人界篇/
├── SKILL.md                     # GM 技能定义
├── service/
│   └── game-rules.md            # 24 模块完整游戏规则引擎
├── scripts/
│   ├── calc.py                  # CLI 统一入口（聚合 42 个函数）
│   └── calculators/             # 概率计算引擎 · 组件化架构

│       ├── calc_utils.py        # 工具函数

│       ├── calc_character.py    # 角色创建

│       └── calc_world.py        # 世界介绍

```

### 核心设计理念

1. **概率强制** — 所有随机判定必须执行 Python 脚本
2. **暗骰机制** — 对玩家仅展示成功/失败
3. **该死必死** — 不设主角光环
4. **动态生成** — 不依赖固定列表
5. **组件化** — 七组件模块架构

## v2.0.0 — 2026-07-23

> 性质：**大更新** — AI 创作自由度最大化
> 核心主题：从"固定菜单式游戏"转型为"AI 动态叙事引擎"
> 向后兼容性：❌ 破坏性变更（移除固定宗门菜单系统）

### 升级概述

v1.x 的游戏开局存在大量固定内容。v2.0.0 彻底翻转设计哲学：所有固定列表被标记为"参考方向"或删除，游戏核心从"菜单驱动"变为"叙事驱动"。AI（GM）现在是真正的创造者。

### 设计原则变更

| 原则 | v1.x | v2.0.0 |
|:-----|:----:|:------:|
| 宗门/势力 | 固定 6 个正道宗门列表 | AI 动态创造 |
| 丹药/法器 | 固定 8 种丹药名 + 属性列表 | 方向性参考，AI 创造具体丹方 |
| 修仙路径 | 菜单选择（正道/邪修/散修 × 13 条） | 叙事自然引出 |
| 事件/秘境 | 固定类型表 + 代表名称 | 方向参考，AI 自由创造 |
| 符箓/阵法 | 固定类型+代表阵法名 | 方向参考，AI 自由命名 |
| 体质/出身 | 描述较固定 | 叙事完全由 AI 发挥 |

### 新增核心原则（§1 第 11 条）

> **AI 自主创造**：本系统不设任何固定菜单选项。所有宗门、势力、功法、丹药、事件、NPC 等均由 AI 根据角色背景和世界情境动态创造。参考列表仅供"灵感种子"——绝不可向玩家展示为固定选项。玩家的每一个选择应来源于叙事，而非菜单。

### 文件级变更清单

| 文件 | 变更 |
|:-----|:------|
| `calc_world.py` | 移除 `_SECT_PARAMS`（13 宗门）、`roll_sect_path()`、`get_sect_by_name()`；新增动态路径生成指南 |
| `__init__.py` / `calc.py` | 移除 `roll_sect_path`、`get_sect_by_name` 导出 |
| `calc_battle.py` | 注释增强：场景/状态/元素可由 AI 自由扩展 |
| `calc_cultivation.py` | 注释增强：失败/天劫/业力标签为叙事种子 |
| `calc_crafting.py` | 注释增强：丹药/法器名称效果由 AI 创造 |
| `calc_beast.py` | 注释增强：灵兽种类/名称由 AI 动态创造 |
| `calc_character.py` | 注释增强：家族故事/体质命名由 AI 发挥 |
| `service/game-rules.md` | 全面软化（12 处），开场模板重写 |
| `SKILL.md` | 新增第 4 条强制规则"AI 自主创造"，移除六步创建流程 |

## v2.1.0 — 2026-07-23

> 性质：小更新 — 出身系统深度清理 + 内容池大幅扩展
> 核心主题：彻底剥离固定叙事文本，AI 拿到的是纯数值种子

### `roll_origin()` 彻底剥离固定叙事

移除 v2.0.0 中残留的硬编码"描述"/"环境特征"文本，返回值改为纯结构化：

| 维度 | v2.0.0 | v2.1.0 |
|:-----|:------:|:------:|
| 家族背景 | 返回 `{"描述": "你是孤儿出身…"}` | 移除"描述"，仅返回 type + numerical effects |
| 出生地 | 返回 `{"环境特征": "宁静，灵气稀薄"}` | 移除全部叙事文本 |
| 特殊事件 | 返回 `{"描述": "你出生时天降异象…"}` | 移除"描述"，仅返回 type + numerical effects |
| 返回值结构 | 扁平 dict | 三层嵌套 `family/birthplace/special_event` 各含 `{type, effects}` |
